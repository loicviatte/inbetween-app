Bouton Stop / End — recommandé ✅

Oui, j'inclus un App Intent (iOS 17+) sur les deux Expanded et sur le Lock Screen banner. C'est l'opportunité rare où l'utilisateur peut terminer une session sans déverrouiller — gros confort, surtout pour le coach pendant un cours. Pour les iOS 16 (sans App Intent), le tap fallback ouvre l'app directement sur l'écran "session en cours" avec le bouton Stop natif au focus.

Pourquoi deux variantes ? — Le coach enregistre du contenu, "Stop" rouge = "j'arrête une capture importante, sois sûr". L'élève termine un timer, "End" neutre = "j'ai fini, c'est chill". Même icône stop.fill, deux contextes, deux niveaux de friction visuelle.

Animations (autorisées et recommandées)

Apple permet quelques animations limitées sur les Live Activities. Trois suffisent :

1. Pulse rec dot — opacité 1 → .55 et scale 1 → .92 sur 1.4s ease-in-out infinite. Stop quand isInterrupted.
2. Progress ring/bar fill — withAnimation(.linear(duration: 1)) entre chaque update du elapsed. Pas de spring, ça doit rester clinique.
3. State color flash — quand on passe à "saved" ou "target reached", flash 600ms vers le vert #4AAF52 puis fade back vers le neutre. Apple le tolère via contentTransition.

❌ Ne pas : Lottie, vidéo, transitions interpolées sur les images bundlées, ou n'importe quoi qui dure > 2s d'un coup. Apple rejette.

Mode sombre / clair — règle simple

Dynamic Island est toujours sombre (BG #000) — rien à faire.
Lock Screen banner : utilise @Environment(\.colorScheme) et bascule entre :
Light → BG #FFFFFF, ink #141414, hairline #E5E5E5.
Dark → BG #1C1C1E, ink #FFFFFF, hairline rgba(255,255,255,0.08).
Les couleurs de signal (#E8A838, #D44545, #4AAF52) ne changent pas entre les deux modes — elles sont assez saturées pour rester lisibles partout.
